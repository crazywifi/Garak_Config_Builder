Step 2: Select Target LLM

What is a Target?

The "target" is the AI model you want to scan. Garak supports cloud APIs (OpenAI, Azure, etc.), local models (Ollama, HuggingFace), and custom REST endpoints for your own LLM apps.

Examples: gpt-4 | gpt-3.5-turbo | llama3.2:3b (Ollama) | mistral-large-latest

⚠️ API Key Required

Set your API key as environment variable before running:

export OPENAI_API_KEY="sk-..."

Step 3: REST API Configuration

🌐 Test Your Own LLM Web App / API

Paste a raw HTTP request from Burp Suite, browser DevTools, or manually configure the endpoint. Mark the input field where test prompts should be injected.

⚠️ Select the INPUT Field

Click on the field where Garak should inject test prompts. Usually called "message", "prompt", "content", "query", or similar.

Replace the actual user message with $INPUT - Garak will inject test prompts there.

JSONPath: $.choices[0].message.content (OpenAI), answer (Gandalf), response

Use $KEY in headers to reference this

Step 7: Configure Buffs (Optional)

What are Buffs?

Buffs transform prompts before sending to the AI. For example: translate to other languages, paraphrase, encode in Base64, or lowercase. This tests if the AI's defenses work against transformed inputs.

✓paraphrase.Fast - T5 paraphrasing ✓paraphrase.PegasusT5 - High-quality paraphrase ✓lowercase.Lowercase - Convert to lowercase ✓encoding.Base64 - Base64 encode ✓encoding.CharCode - Character codes ✓low_resource_languages.LRLBuff - Translate to low-resource languages
